# ApuShape: Human-in-the-Loop Annotation Software

Please download the latest version of ApuShape from the [Releases](https://github.com/BUAA-LiuLab/ApuShape/releases) section.

## Overview

ApuShape is human-in-the-loop annotation software specifically designed for Deep Visual Proteomics (DVP) and large-scale spatial omics studies. It addresses the critical need for accurate nucleus annotation in fluorescence microscopy images by integrating:

- **ShapeStar**: Contour-level nucleus instance segmentation  
- **ShapeActive**: Human-in-the-loop active learning strategy  
- **ShapeRefine**: Boundary refinement algorithm

This integrated approach enables rapid creation of high-quality nucleus annotation datasets with expert-level accuracy while significantly reducing manual effort.

## System Requirements

- **RAM**: 8 GB minimum, 16 GB or higher recommended
- **OS**: Windows 10/11 (64-bit) or higher
- **Display**: Optimal at 2560×1440 resolution with 125% scaling

## GPU Acceleration

ApuShape supports GPU acceleration for enhanced performance. Requirements:
- NVIDIA GPU (GTX 1050 or newer)
- Latest NVIDIA drivers installed
- Verify driver installation by running `nvidia-smi` in the console
